# Standard operating procedures (SOPs)

Add one markdown file per procedure. Suggested naming: `{area}-{action}.md` (e.g. `paid-campaign-launch.md`).

## SOP template

Each SOP should include:

- **Purpose** — why this exists
- **Owner** — role responsible
- **When to use** — trigger events
- **Steps** — numbered checklist
- **Tools** — links to templates or folders
- **Definition of done** — how to verify completion

## Starter SOPs to add

- Monthly reporting cycle
- New campaign launch (see also `tools/checklists/campaign-launch.md`)
- Creative review and approval
- Client escalation
