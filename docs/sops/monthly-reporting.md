# SOP: Monthly client reporting

## Timeline

| Day | Action |
|-----|--------|
| 1–3 | Pull data (GA4, ads, CRM, social) |
| 4–5 | Draft using `templates/monthly-report.md` |
| 6 | Internal QA |
| 7 | Send to client; store PDF in `clients/<slug>/reports/YYYY-MM/` |

## Quality checklist

- [ ] Period dates and comparison (MoM / YoY) correct
- [ ] Insights tie to client goals, not vanity metrics only
- [ ] Next-month recommendations are specific and owned
- [ ] Screenshots / exports labeled with date

## Escalation

If performance drops >20% on primary KPI, flag account lead before sending.
