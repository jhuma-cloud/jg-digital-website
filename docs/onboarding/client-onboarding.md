# Client onboarding

## Pre-kickoff

- [ ] Contract signed → `operations/contracts/`
- [ ] Invoice / deposit processed → `operations/invoicing/`
- [ ] Client folder created from `clients/_template-client/`
- [ ] Stakeholders & access documented in `clients/<slug>/README.md`

## Kickoff (week 1)

- [ ] Discovery call — notes in `clients/<slug>/briefs/`
- [ ] Access: analytics, ads, CMS, social (track in client README, not in git secrets)
- [ ] Goals & KPIs aligned → `analytics/kpi-framework.md` (client copy in `reports/`)
- [ ] Communication cadence agreed (weekly / biweekly)

## Handoff to delivery

- [ ] Campaign brief completed → `templates/creative-brief.md`
- [ ] Content calendar draft → `templates/content-calendar.md`
- [ ] Launch checklist → `tools/checklists/campaign-launch.md`

## Sign-off

- [ ] Client approves measurement plan
- [ ] PM schedule in `operations/project-management/`
