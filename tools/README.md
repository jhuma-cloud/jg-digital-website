# Tools

Lightweight checklists and helpers — no heavy scripts required. Add scripts under `tools/scripts/` only when they save real time.

| Path | Purpose |
|------|---------|
| `checklists/` | Operational checklists (launch, QA, onboarding) |

Prefer markdown over code for portability across the team.

**Canonical checklists:** `checklists/campaign-launch.md`, `checklists/new-hire-week-one.md`
