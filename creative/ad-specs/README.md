# Ad specifications

Quick reference for common ad dimensions. Verify against each platform's current docs before production.

## Meta (Feed)

| Placement | Size | Ratio |
|-----------|------|-------|
| Feed image | 1080×1080 | 1:1 |
| Feed link | 1200×628 | 1.91:1 |

## Google Display

| Placement | Size |
|-----------|------|
| Medium rectangle | 300×250 |
| Leaderboard | 728×90 |

## LinkedIn

|-----------|------|
