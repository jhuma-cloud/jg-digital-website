# Templates

Reusable deliverable starters. Copy into `clients/`, `sales/`, or `projects/` and rename with client and date.

| File | Use |
|------|-----|
| `proposal.md` | New business proposals |
| `report.md` | Client performance reports |
| `creative-brief.md` | Campaign creative requests |
| `content-calendar.md` | Editorial planning |

Do not edit masters in place for client work — duplicate first.
