# KPI frameworks

Define metrics per service so reporting stays consistent across clients.

## Suggested files

- `seo-kpis.md` — rankings, organic traffic, conversions
- `paid-kpis.md` — ROAS, CPA, MER
- `social-kpis.md` — reach, engagement, follower growth
- `content-kpis.md` — traffic, time on page, assisted conversions

Each framework: definition, data source, reporting frequency, good/better/best benchmarks.
